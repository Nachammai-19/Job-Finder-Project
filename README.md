# JobFinder – Job Application Portal

## About the Project
JobFinder is a responsive job application portal developed using HTML, CSS, and JavaScript. It helps users explore job opportunities by searching for job titles and locations.

## Features
- Search jobs by title and location.
- View detailed job information, including required skills and experience.
- Apply for jobs using an application form.
- Validate application form fields.
- Store submitted application details in browser localStorage.
- Responsive design for desktop and mobile screens.
- Clear search filters and display a message when no jobs match.

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser localStorage

## How to Run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
